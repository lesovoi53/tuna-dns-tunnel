# Изменения

## 0.1.0 — 2026-10-23

Стабильный выпуск TUNA DNS Tunnel.

- Поддержка только Debian 12/13, amd64, systemd, Python 3.11+.
- Самостоятельная установка без X-Manager, Direct и внешний SOCKS5, экспорт TUNA/StormDNS.
- Исправление редактора доменов включено: ошибки не сбрасывают черновик.
- Установка и работа проверены на VPS Debian 13, включая обновление, откат, восстановление и перезагрузку.


## 0.1.0-rc2 — 2026-10-23

- Исправлен редактор доменов: удаление всех доменов допускается в черновике для замены, ошибки ввода и попытка сохранения пустого списка больше не закрывают меню и не теряют изменения.
- Добавлены регрессионные тесты сценариев удаления и ошибочного ввода.

## 0.1.0-rc1 — 2026-10-23

- Первый самостоятельный установщик TUNA DNS Tunnel для серверов без X-Manager.
- Домены одного сервера, выбор шифрования и ключа, Direct или внешний SOCKS5 с авторизацией.
- Экспорт StormDNS отдельно на каждую зону и TUNA со всеми зонами.
- Редактор параметров экспортируемых профилей; исходные значения совпадают с Lite v2026.10.23.2.
- Собственные службы, правила firewall, резервное копирование, восстановление и откат при ошибках.
- В архив включено закреплённое ядро MasterDnsVPN; проверка SHA256 перед установкой.
- Предварительный выпуск: полноценная установка на чистой VPS и перезагрузка ещё требуют проверки.
