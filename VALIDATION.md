# Проверка 0.1.0-rc1

23 октября 2026: 41 тест в Linux/WSL, все прошли, пропусков нет. Проверены конфигурация, сохранение/отмена черновика, маскирование ключей, экспорт и точное соответствие пресетов Lite, безопасное чтение архивов, занятый порт, чужие файлы и службы, права файлов, UFW/iptables с подменой команд, откат при сбоях, резервное копирование и сохранение остановленного состояния при обновлении.

`bash -n install.sh bin/tuna-dns` и запуск предварительного просмотра меню прошли.

Настоящие MasterDnsVPN Server `7de2476` и StormDNS Client проверены в отдельном Linux network namespace. Клиент установил DNS-туннель с двумя зонами и передал HTTP-запрос через него к тестовому серверу. Четыре сценария прошли:

1. Прямой выход.
2. Выход через тестовый SOCKS5 без авторизации.
3. Выход через тестовый SOCKS5 с логином/паролем.
4. Недоступный SOCKS5: запрос отклонён, прямого обхода не было.

Использованы только синтетические ключи и пароли. Для воспроизведения нужны бинарник StormDNS Client и его sample TOML (в серверный дистрибутив не входят):

```bash
sudo unshare -n bash
ip link set lo up
ip addr add 203.0.113.1/32 dev lo
PYTHONPATH=. python3 tests/native_smoke.py --server-archive assets/masterdns-amd64.tar.gz --client /absolute/path/stormdns-client --sample /absolute/path/client-sample.toml
exit
```

Документальный адрес существует только внутри изолированного пространства. Проверка loopback-назначения непригодна: исходное ядро его блокирует. Сеть хоста и службы при тесте не меняются.

**Ещё не проверено:** установка на чистой VPS с настоящей systemd, реальное применение UFW/iptables и их сохранение после перезагрузки, публичное DNS-делегирование нового сервера, импорт ссылок этой версии на физическом Android-устройстве и длительная работа. Fixture-тесты не заменяют эти проверки. Производственные серверы этим установщиком не изменялись.

Тестовый Linux StormDNS Client поддерживает стратегии 0–3 и отвергает 5 при запуске. Поэтому транспортный smoke использует стратегию 3; экспорт по требованию сохраняет стратегию 5 как на основных серверах. Передача данных с экспортированными настройками стратегии 5 на актуальном Android-клиенте в этом выпуске не проверена.
